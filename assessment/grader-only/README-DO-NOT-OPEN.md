# Grader-Only Materials — Do Not Open Before Testing

This directory contains answer keys, scoring information, item tags, rubrics, and grading procedures.

Reading these files before completing the learner assessment will invalidate the attempt as an unaided progress measurement because the materials reveal answers and what individual questions are designed to test.

Finish the assessment and the submission checklist first. After that, include this directory when you submit the completed assessment to a grader AI.

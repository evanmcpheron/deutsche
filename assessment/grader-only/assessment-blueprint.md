# Assessment Blueprint

**Assessment Version:** `A1-WRITTEN-20260817-F2F2`  
**Blueprint Version:** `A1-Written-1.0`  
**Source Research Date:** 2026-08-17

## Design Summary

This blueprint defines a written/non-oral German A1 progress assessment. It intentionally excludes listening, speaking, pronunciation, and oral interaction.

The A1 core contains **144 scored response opportunities**, including four independent writing tasks. The separate A2 ceiling contains **12 response opportunities** and is excluded from the A1 score.

### Domain Weights

| Domain | Weight | Core raw maximum |
|---|---:|---:|

| Reading Comprehension | 25% | 34 |
| Written Production | 25% | 80 |
| Grammar & Sentence Structure | 15% | 38 |
| Vocabulary & Lexical Control | 15% | 30 |
| Functional Communication & Pragmatics | 15% | 28 |
| Orthography & Written Conventions | 5% | 10 |
| **Total** | **100%** | **220 raw points across domain-specific scales** |

Raw point totals are **not** added directly across domains to create the overall score. Each domain is first normalized to 0–100; then the specified domain weights are applied.

### Response Modes

| Mode | Meaning | Core raw maximum |
|---|---|---:|
| R | Recognition/receptive evidence | 70 |
| CP | Controlled Production | 70 |
| IP | Independent Production | 80 |

Mode indices are diagnostic views only and are never added to the overall score.

### Difficulty Distribution

Difficulty labels are:
- **straightforward/core** — direct, high-frequency A1 material;
- **normal A1** — ordinary A1 integration of form and meaning;
- **upper-A1** — demanding but source-supported A1 material;
- **A2 ceiling** — excluded from A1 scoring.

### Reliability Rule

A precise subtopic percentage should normally be reported only when there are at least **three reasonably direct evidence points across at least two contexts**. If there are fewer, report **Insufficient evidence** unless independent writing clearly corroborates a pattern. A single incidental writing error is never enough for a precise subtopic score.

## Coverage Principles for Equivalent Retests

Equivalent future versions must preserve:

- the six domain weights and competency floors;
- approximately the same raw evidence density by domain;
- approximately 70 recognition points, 70 controlled-production points, and 80 independent-production points;
- four independent writing tasks with comparable freedom and functional demand;
- a mixture of straightforward/core, normal A1, and upper-A1 items;
- broad sampling across personal information, family, daily life, home, food/drink, shopping, time, numbers, work/study, hobbies, transport/travel, places/directions, weather, basic health, descriptions, and basic social interaction;
- current source-supported A1 grammar coverage;
- a separate A2 ceiling that never lowers the A1 result.

New versions must change surface content rather than simply reshuffle options.

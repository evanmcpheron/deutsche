Use this section when you are **adding something**, **restricting what counts**, or describing **degree or amount**.

| Meaning or problem | Best page to open |
|---|---|
| “also / too / as well” — adding a person or thing | [`auch`](words/auch.md) |
| “only / just” — limiting the possibilities or amount | [`nur`](words/nur.md) |
| “one more / another” of the same thing | [`noch ein …`](patterns/noch-ein.md) |
| Choosing “also” versus “another / additional” | [`auch` vs. `noch`](comparisons/auch-vs-noch.md) |
| “very” — increasing intensity | [`sehr`](words/sehr.md) |
| “too” — excessive degree, as in `zu teuer` | [`zu`](prepositions/zu.md) — see the non-preposition use |
| “a little / a bit” — small amount or mild degree | [`ein bisschen`](patterns/ein-bisschen.md) |
| Intensity versus quantity (`sehr` vs. `viel`) | [`sehr` vs. `viel`](comparisons/sehr-vs-viel.md) — **Later:** learn basic `viel` first |
| “only so far / less than expected” | [`erst`](words/erst.md) — **Recognition** |

**Related concepts:** [Time and change](#time-and-change), because `noch`, `schon`, and `erst` often add an expectation about how far a situation has progressed; [Uncertainty and softening](#uncertainty-and-softening), because `ein bisschen` can make a statement less strong.

## Time and change

Use this section when you are trying to show whether a situation is **continuing, completed, repeated, current, or earlier/later than expected**.

| Meaning or problem | Best page to open |
|---|---|
| “still / another / more” — something has not run out yet | [`noch`](words/noch.md) |
| “already / yet” — something has happened by now | [`schon`](words/schon.md) |
| Distinguishing “still” from “already” | [`noch` vs. `schon`](comparisons/noch-vs-schon.md) |
| “not yet” | [`noch nicht`](patterns/noch-nicht.md) |
| “no longer / not anymore” | [`nicht mehr`](patterns/nicht-mehr.md) |
| Distinguishing a continuing state from an ended state | [`nicht mehr` vs. `noch`](comparisons/nicht-mehr-vs-noch.md) |
| “always / every time” | [`immer`](words/immer.md) |
| “still, even now” — continuing longer than expected | [`immer noch`](patterns/immer-noch.md) |
| “again / back” — a state or action stopped and returned | [`wieder`](words/wieder.md) |
| Distinguishing uninterrupted continuation from a restart | [`noch` vs. `wieder`](comparisons/noch-vs-wieder.md) |
| “only so far / not until / first” | [`erst`](words/erst.md) — **Recognition** |
| Comparing “only so far” with “already” | [`erst` vs. `schon`](comparisons/erst-vs-schon.md) — **Recognition** |
| “right now / just” — the exact current moment | [`gerade`](words/gerade.md) — **Recognition** |
| `gerade` versus general “now” | [`gerade` vs. `jetzt`](comparisons/gerade-vs-jetzt.md) — **Later:** learn basic `jetzt` first |
| “ever / at some point before now” | [`schon mal`](patterns/schon-mal.md) — **Recognition** |

For time expressed with prepositions — such as *at eight*, *after work*, or *from Monday to Friday* — see [Time expressions with prepositions](#time-expressions-with-prepositions).

**Related concepts:** [Negation](#negation) for `noch nicht` and `nicht mehr`; [Amount, addition, and limitation](#amount-addition-and-limitation) for the expectation meanings of `erst` and `schon`.

## Movement and destination

Use this section when English gives you a broad word such as **“to,” “into,” or “home”** and you need the German relationship.

| Destination or movement | Best page to open |
|---|---|
| Going to a person or most everyday places/buildings | [`zu`](prepositions/zu.md) |
| Going to a city, most countries without an article, a direction, or home | [`nach`](prepositions/nach.md) |
| Choosing `zu` versus `nach` | [`zu` vs. `nach`](comparisons/zu-vs-nach.md) |
| Being at home versus going home | [`zu Hause` vs. `nach Hause`](comparisons/zu-hause-vs-nach-hause.md) |
| Going into a room/building or into a country that takes an article | [`in`](prepositions/in.md) |
| Choosing `in` versus `nach` for destinations | [`in` vs. `nach`](comparisons/in-vs-nach.md) |
| Moving onto a surface or into certain idiomatic destinations | [`auf`](prepositions/auf.md) |
| Moving up against a surface or edge | [`an`](prepositions/an.md) — **Recognition** |

For `in`, `auf`, and `an`, the key distinction is **location versus movement**, not simply the English preposition. Use [Cases at a Glance](reference/cases-at-a-glance.md) for the *Wo?* / *Wohin?* case test.

**Related concepts:** [Location and spatial relationships](#location-and-spatial-relationships) for the same `in` / `auf` / `an` system when nothing is moving; [Source, origin, and range](#source-origin-and-range) for movement **from** a place.

## Time expressions with prepositions

Use this section for **clock times, sequence in time, duration, and ranges**. These meanings overlap with the general [Time and change](#time-and-change) system, but the retrieval problem here is usually which preposition or fixed pattern to use.

| Time relationship | Best page to open |
|---|---|
| At a clock time: `um acht Uhr` | [`um`](prepositions/um.md) |
| After an event or time: `nach der Arbeit` | [`nach`](prepositions/nach.md) |
| In a month, season, or period: `im Juli`, `in einer Stunde` | [`in`](prepositions/in.md) |
| On a day or part of the day: `am Montag`, `am Abend` | [`an`](prepositions/an.md) — **Recognition** |
| A duration or period intended for something | [`für`](prepositions/fuer.md) |
| While/during an activity, such as `beim Essen` | [`bei`](prepositions/bei.md) |

**Related concepts:** [Time and change](#time-and-change) for *still / already / again / not yet / no longer*; [Source, origin, and range](#source-origin-and-range) for the broader `von … bis …` pattern.

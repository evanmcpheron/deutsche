# noch ein …

**Type:** Pattern (chunk)
**Means:** another one, one more
**Level:** A1 · **Tier 1** · **Active**

## What It Means

*noch ein …* = **another / one more of the same thing.** There was already one; now you want a second.

The [noch](../words/noch.md) here is the "hasn't run out" idea applied to a supply: the drinking isn't finished, so there's room for one more.

## In Use

**Noch einen Kaffee, bitte.**
Another coffee, please.

**Möchtest du noch ein Bier?**
Would you like another beer?

**Wir brauchen noch einen Stuhl.**
We need one more chair.

**Noch ein Glas Wasser, bitte.**
Another glass of water, please.

## The Article Changes with the Noun

*ein* takes the ending it would take anyway — and after verbs like *möchten*, *brauchen*, *nehmen*, that's the **accusative**:

| Noun | Pattern |
|---|---|
| der Kaffee | noch **einen** Kaffee |
| das Bier | noch **ein** Bier |
| die Cola | noch **eine** Cola |
| plural | noch **zwei** Bier / noch **etwas** |

**Noch einen Kaffee, bitte** is the single most useful version of this pattern to have ready in a café.

## Related Forms

- **noch etwas** — something else: *Noch etwas?* — Anything else?
- **noch einmal / noch mal** — one more time: *Sag das noch mal.*
- **noch zwei / noch drei …** — two more, three more: *Noch zwei Bier, bitte.*
- **noch ein bisschen** — a little more → [ein bisschen](ein-bisschen.md)

## What Changes Without It?

**Einen Kaffee, bitte.**
A coffee, please. *(your first)*

**Noch einen Kaffee, bitte.**
Another coffee, please. *(you've had one)*

Both are polite and both work. *noch* just tells the server this is a repeat order — which is exactly what they're asking when they say *Noch etwas?*

## Common Mistakes

- **Using *ein anderer*.** *ein anderer Kaffee* means a *different* coffee — a different kind — not one more of the same.
- **Dropping the ending.** *Noch ein Kaffee* is understood everywhere and you'll hear it, but the careful form is *noch einen Kaffee*.
- **Using *wieder*.** *wieder* means the event repeats, not that you want a second serving.
- **Adding *mehr*.** *noch mehr Kaffee* means "even more coffee" (a larger quantity), not "one more cup."

## Words Whose Canonical Page Is Elsewhere

Three words could reasonably sit in this folder or in `particles/`. This repository resolves that with one rule, applied everywhere:

> **If a word's main A1-relevant use is as a modal particle — shaping tone or attitude rather than contributing core meaning — its canonical page lives in [`particles/`](../particles/README.md). Otherwise it lives here in `words/`.**

That puts these three in `particles/`, with only a short stub here:

- [doch](doch.md) → full page at [particles/doch.md](../particles/doch.md)
- [mal](mal.md) → full page at [particles/mal.md](../particles/mal.md)
- [eigentlich](eigentlich.md) → full page at [particles/eigentlich.md](../particles/eigentlich.md)

The same rule decides any future placement question, so the answer never depends on which page you happen to be reading.
